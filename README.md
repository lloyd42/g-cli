# g-cli

`g-cli` 是一个轻量级、可扩展的前端项目脚手架工具，旨在帮助您快速地从预设或自定义的模板创建新项目。

## ✨ 功能特性

- **快速创建**: 通过 `create` 命令，从模板快速生成新项目。
- **模板管理**:
  - 使用 `list` (`ls`) 命令查看所有可用的模板。
  - 使用 `add` 命令添加您自己的常用模板。
  - 使用 `delete` (`rm`) 命令移除不再需要的自定义模板。
- **自动化流程**:
  - 在项目创建后，可选择自动安装依赖。
  - 在项目创建后，可选择自动初始化 Git 仓库。
- **灵活扩展**: 默认模板和用户自定义模板分离，方便您打造个性化的模板库。

## 📦 安装

要全局安装 `g-cli`，请运行以下命令：

```bash
npm install -g .
```

*(请在 `g-cli` 项目根目录下运行此命令)*

安装完成后，您就可以在任何地方使用 `my-cli` 命令了。

## 🚀 使用方法

### 1. 创建新项目

这是 `g-cli` 的核心功能。运行以下命令开始创建项目：

```bash
my-cli create
```

程序将会引导您完成以下步骤：

1. 输入您的项目名称。
2. 从模板列表中选择一个项目模板（包括默认模板和您自定义的模板）。
3. 确认是否覆盖同名目录（如果存在）。
4. 下载模板后，询问是否自动安装项目依赖。
5. 安装依赖后，询问是否自动初始化 Git 仓库。

### 2. 管理模板

`g-cli` 允许您管理一个自己的模板列表。

#### 列出所有模板

要查看所有可用的模板（包括默认模板和您的自定义模板），请运行：

```bash
my-cli list
# 或者使用别名
my-cli ls
```

#### 添加一个新模板

您可以将任何 Git 仓库作为模板添加到您的列表中：

```bash
my-cli add <template-name> <git-repository-url>
```

例如：

```bash
my-cli add svelte-template https://github.com/user/svelte-template.git
```

#### 删除一个自定义模板

要从您的列表中移除一个模板，请运行：

```bash
my-cli delete <template-name>
# 或者使用别名
my-cli rm <template-name>
```

**注意**: 您不能删除 `g-cli` 预设的默认模板。

### 3. 查看配置

要查看用户自定义模板的配置文件 (`user-templates.json`) 的存储路径，请运行：

```bash
my-cli config
```
